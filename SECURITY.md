# Security policy

Please do not open a public issue for a vulnerability or include production
calendar URLs, subscription tokens, database exports, credentials, or user
data in an issue or pull request.

Report vulnerabilities privately through GitHub's **Report a vulnerability**
feature on this repository. If that feature is unavailable, contact the
repository owner through their GitHub profile.

Only the latest deployed version is supported. Subscription URLs are bearer
credentials: anyone who has one can read that filtered calendar.
