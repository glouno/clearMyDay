# Email de Demande de Déblocage - Version Finale

## Version avec Information Technique Vercel

```
Objet : Demande de déblocage du site clearmyday.com

Bonjour,

Je suis étudiant en Master 1 Informatique (MIND) à Sorbonne Université.

J'ai développé un outil web https://www.clearmyday.com permettant aux étudiants 
de filtrer et personnaliser leur emploi du temps universitaire, afin de générer 
un lien d'abonnement compatible avec Apple / Google Calendar.

Actuellement, le site n'est pas accessible via le WiFi Sorbonne :
- le pare-feu bloque l'accès en le classant dans la catégorie "web hosting" 
  ou "newly-registered domain" ;
- le certificat SSL est remplacé, rendant la connexion non valide.

INFORMATIONS TECHNIQUES :
Le site est hébergé sur Vercel, une plateforme d'hébergement cloud qui utilise 
des adresses IP dynamiques via un réseau CDN (Content Delivery Network). 
L'adresse IP actuelle est 216.198.79.1, mais celle-ci peut changer sans préavis 
pour optimiser les performances et la disponibilité.

Pour cette raison, je vous recommande un déblocage par nom de domaine plutôt 
que par adresse IP fixe, afin d'assurer un accès stable dans le temps.

Pourriez-vous envisager d'ajouter ces domaines à la liste blanche :
- clearmyday.com (URL principale)
- clearmyday.xyz (redirection)

DÉTAILS TECHNIQUES (si nécessaire pour vos règles de filtrage) :
- Port : 443 (HTTPS)
- Protocole : HTTPS (TCP)
- IP actuelle : 216.198.79.1 (susceptible de changer - hébergement Vercel/CDN)

Cet outil est déjà utilisé par plusieurs étudiants de Master Informatique et 
leur permet d'éviter de charger la totalité des calendriers disponibles sur 
https://cal.ufr-info-p6.jussieu.fr/master/, réduisant ainsi la charge et 
améliorant l'accessibilité.

Je vous remercie par avance pour votre aide et reste à disposition pour toute 
précision ou information complémentaire.

Cordialement,
Paul Béglin
M1 Informatique – Parcours MIND
```

Port            : 443
Protocole       : HTTPS ou TCP
```

> "Le site utilise des IPs dynamiques (Vercel/CDN). IP actuelle : 216.198.79.1, 
> mais un déblocage par domaine est préférable pour éviter des mises à jour 
> futures."
```

## Recommandation

**Utilisez la première version (complète)** si vous voulez :
- Maximiser vos chances d'acceptation
- Montrer que vous comprenez les aspects techniques
- Faciliter leur travail en donnant tous les détails

**Utilisez la deuxième version (courte)** si vous préférez :
- Un email plus concis
- Moins de jargon technique
- Laisser le service réseau vous poser des questions si besoin

Les deux versions sont professionnelles et complètes. Je recommande la **première version** car elle anticipe leurs questions techniques.
